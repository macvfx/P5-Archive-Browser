# P5 Archive Browser 0.39 (build 64)

A small follow-up to 0.38.

## Fixed

- **Catalog Tools showed its figures at the far edge of the window.** Storage used and
  Reclaimable space each had the label on the left and the value at the right edge, so
  pairing "Reclaimable space" with "None" meant reading across the whole width. Each
  figure now sits beside its label.

Everything 0.38 introduced is unchanged: Compact Catalog, backups that do not block the
app, Catalog History and the Settings sidebar. See
[the 0.38 notes](RELEASE_BLURB_0.38_BUILD_63.md).

The version number moves, rather than only the build, so that managed installs see this
as an update.

---

Requires macOS 14.6 or later. Universal, signed and notarized.
